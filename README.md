# DishCrafter

Android-приложение, которое генерирует рецепты блюд на основе продуктов, введённых пользователем.

## Цель

Помочь пользователю быстро найти, что приготовить из имеющихся продуктов — без лишних поисков и листания сайтов. Достаточно ввести список ингредиентов, и ИИ предложит готовый рецепт с пошаговой инструкцией.

## Функционал

- Ввод списка продуктов в текстовое поле
- Генерация рецепта с помощью ИИ (название блюда, ингредиенты с количеством, пошаговое приготовление, время)
- Копирование рецепта в буфер обмена

## Стек

| Слой | Технология |
|---|---|
| UI | Jetpack Compose + Material 3 |
| Архитектура | MVVM (ViewModel + StateFlow) |
| Сеть | OkHttp |
| AI API | Groq API (Llama 3.3 70B) |
| Язык | Kotlin |
| Min SDK | 26 (Android 8.0) |

## Настройка

1. Получи бесплатный API ключ на [console.groq.com](https://console.groq.com)
2. Добавь в `local.properties`:
```
AI_API_KEY=твой_ключ
```
3. Собери и запусти проект
